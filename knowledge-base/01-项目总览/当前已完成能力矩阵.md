# 当前已完成能力矩阵

## 读取说明

这个矩阵优先表达“当前可以如何理解能力边界”，不是逐条 opcode 的完整真值表。

## Direct-consumer 与 Branch 能力

| 能力线 | 当前状态 | 说明 |
|---|---|---|
| `CMN / ADDS xzr -> ADC` | 已完成 | 属于 direct-consumer 主线 |
| `CMP / SUBS xzr -> SBC` | 已完成 | 属于 direct-consumer 主线 |
| `ADDS rd -> ADC / ADCS` | 已完成 | 已纳入 direct-consumer 能力 |
| `SUBS rd -> SBC / SBCS` | 已完成 | 已纳入 direct-consumer 能力 |
| `ADCS/SBCS -> ADC/SBC/ADCS/SBCS` | 已完成 | 目前仍是稳定主线的一部分 |
| bounded-gap `CMP/SUBS xzr -> B.cond` | 已完成 | phase 2 第一轮 rollout |
| bounded-gap `CMN/ADDS xzr -> B.cond` | 已完成 | add-side 已打开 |
| bounded-gap `ADCS/SBCS rd -> B.cond` | 已完成但有边界 | 相邻 materialized carry-producer branch 用户仍保守 |

## Compare-like Non-branch 能力

| 能力线 | 当前状态 | 说明 |
|---|---|---|
| compare-like `CSEL/CSINC/CSINV/CSNEG/CSET/CSETM` | 已恢复 | 采用 rework 后的新模型 |
| compare-like `CCMP/CCMN` | 已完成 | 当前主线可用 |
| compare-like `FCSEL` | 已完成 | 当前主线可用 |
| compare-like `FCCMP` | 已完成 | 当前主线可用 |

## 刻意保留的 fallback

| 路径 | 当前状态 | 原因 |
|---|---|---|
| `CMN -> ADCS` | fallback | compare-like producer 的 carry 不是稳定 live host `CF` |
| `CMP -> SBCS` | fallback | compare-like borrow/carry 语义没有被当作稳定可直接复用的 materialized carry |
| 非 whitelist gap 指令后的 lazy consume | fallback / invalidation | 当前模型是 bounded-gap whitelist |
| 跨 TB / page boundary 的延续 consume | 不支持 | 当前设计显式保守 |

## 生命周期层面的能力边界

- 当前 direct-path 并不意味着“producer 信息可无限活着”
- 当前 phase 2 更接近“有限寿命 + whitelist + explicit invalidation”
- compare-like `CSEL/CS*` 当前不是继续保留 pending compare，而是消费条件后退回稳定 flags

## 新近扩展的能力面

根据 `366b7d6ddb` 和 `0c9d65605b` 的提交内容以及新增测试命名，当前还应把下面这些视为“已经进入当前分支的新能力方向”：

- logic producer 相关 direct checks
- `cmp -> csel -> bcond`、`cmp -> csel -> ccmp` 等链式组合
- `cmp -> ccmp -> ...` 的多步 producer chain

这里的更细解释见 [[NZCV direct paths 与 producer chaining 当前状态]]。这部分是当前知识库对最新提交的归一化总结，`progress.md` 还没有完全重写到这层粒度。
