# 知识库首页

## 这是什么

这是仓库内面向人的 Obsidian 知识库，用来整理 AArch64 guest on x86 host TCG
NZCV direct-path / lazy compare 优化线到目前为止的：

- 项目背景与目标
- 当前代码与能力状态
- 关键机制模型
- 方案演进与设计取舍
- 功能正确性与性能证据
- 后续路径选择与代码审视要点

它不是 `progress.md` 的镜像，也不替代 `progress.md`。

## 这不是啥

- 不是 AI 交接文档
- 不是每天的流水账
- 不是所有原始 spec/plan/archive 的简单汇总

运行态、可直接继续执行的上下文仍然优先看 [[维护规范]] 中定义的
`progress.md`。

## 推荐入口

- 想先知道当前做到哪：[[当前状态总览]]
- 想知道为什么当前代码基线恢复到 `6d40860fef`：[[2026-04-13 正收益基线恢复]]
- 想先知道项目为什么值得做：[[项目背景与目标]]
- 想看整个演进轨迹：[[NZCV 优化主时间线]]
- 想理解核心机制：[[TCG direct-path 与 lazy compare 基本模型]]
- 想理解当前 correctness / performance 证据：[[功能正确性总览]]、[[性能结果总览]]
- 想直接看某条优化线：[[ADCS-SBCS Direct-Consumer 优化线]]、[[Lazy Compare Phase 2 - B.cond]]

## 主要阅读维度

- 项目总览：[[项目背景与目标]]、[[当前状态总览]]
- 机制与架构：[[AArch64 NZCV 与宿主 x86 flags 的关系]]、[[pending_cc 与 producer-consumer 生命周期]]
- 优化专题：[[Compare-like CSEL-CS 重构]]、[[NZCV direct paths 与 producer chaining 当前状态]]

## 阅读原则

- 把这里当成“人类理解层”，不是“机器运行层”
- 先看结论，再追到机制与证据
- 如果发现某条结论和 `progress.md` 不一致，优先比较各自的 `as_of`
- 若需要继续自动化推进代码，回到 `progress.md`
